# Moteur de référence

Le dossier `source/` est une référence externe figée. Traitez tous ses fichiers en lecture seule. N’éditez, ne régénérez et ne remplacez aucun fichier dans ce dossier. Ne changez pas sa révision Git sans demande explicite de l’utilisateur.

Placez les adaptateurs, les contrôles et les tests dans AGLLM, en dehors de `source/`. Rétablissez la protection avec `npm run motor:protect` si nécessaire.
